POST /api/tip/print Go to top

Print text to the thermal printer (without adding a newline at the end)

REQUIRED Parameters:

- data: The text to print

OPTIONAL Parameters:

- align: One of: left, center, right, DEFAULT=left; Align the printed data to the left, center or right

- underline: One of: off, onedot, twodot, DEFAULT=off; Underline the printed text

- inverse: true or false, DEFAULT=false; Print white-on-black

- upside_down: true or false, DEFAULT=false; Print upside-down

Example:

/api/tip/print?data=This+will+be+printed

POST /api/tip/println Go to top

Print text to the thermal printer (with adding a newline at the end)

OPTIONAL Parameters:

- data: The text to print; If this parameter is not supplied, just advances the paper 1 line

- underline: One of: off, onedot, twodot, DEFAULT=off; Underline the printed text

- inverse: true or false, DEFAULT=false; Print white-on-black

- upside_down: true or false, DEFAULT=false; Print upside-down

Example:

/api/tip/println?data=This+will+be+printed
